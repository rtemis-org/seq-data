# seq-data: Proteomic &amp; Genomic Data Sharing

## Introduction

This is a public repository for sharing protein sequence & annotation data.

## A3 Data preparation & uploading

1. Use any of the [A3 packages](https://a3.rtemis.org) or [rtemislive](https://live.rtemis.org) to format your data in the before uploading it to this repository.
2. Open a pull request to upload your `A3` dataset(s) under `data/a3`.
